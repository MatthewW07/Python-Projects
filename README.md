# Python-Projects

dis repo has lot of random python projects that i've done. some good, some not good. here summary:

1. Asteroids: Classic asteroids game. Uses *turtle*. Ugly GUI.
2. Calculator: Calculator w/ unit conversion. Uses *ttkinter*. Ugly GUI.
3. Catch-a-Turtle: Game where you click on circle as many times as can. Uses *turtle*. Ugly GUI.
4. **Cellular-Automata**: Game of Life, Multi-Neighbor, and One-Neighbor cellular automata simulations; by "neighbor" I refer to the number of rings around a cell that contribute to the simulation logic. Uses *numpy* and *pygame* and *random*. Pretty graphics, but multi-neighbor has ugly GUI attached.
5. Guess-the-Number: Guess the number game. Uses *random*. No GUI (terminal-only).
6. Maze-Game: Random maze game. Uses *turtle* and *random*. Ugly GUI.
7. Minesweeper: Minesweeper game along with an AI to play it; the AI sucks but does stuff. Uses *torch* and *pygame* and *random* and *numpy* (maybe). Nice GUI.
8. Monte-Carlo: Where I put my Monte-Carlo scripts. Uses *numpy* and *matplotlib*. Alright GUI.
9. Physics: *Falling Sand* and *Particles* simulations. Uses *numpy* and *pygame*. Nice GUI
10. Rotating-Cube: Rotating cube (and other shapes) in pygame and turtle. Uses *pygame* and *turtle*. Alright GUI
11. Scratch-Neural-Network: Neural Network with *only numpy* to recognize digits from mnist.npz file; lets the user draw numbers too. Uses *numpy* and *pygame*. Decent GUI.
12. Snake: Snake game along with an AI to play it; the AI works eventually, but definitely limited (keeps putting itself in a loop...). Uses *torch* and *pygame* and *numpy*. Alright GUI.
13. Tic-Tac-Toe: Tic-Tac-Toe game. Uses *turtle*. Difficult GUI (might have to use terminal...)
14. Turtle-Art: Minskowski's Triangle, Recursive Tree, cool Snowflake, maybe some other stuff. Uses *turtle*. Very nice GUI.
